# serbian_learn

Интерактивные тренажёры сербского для русскоговорящих. Каждый тест — один HTML-файл, открывается в любом браузере без установки.

- `biti-quiz.html` — глагол biti в настоящем: sam, si, je, smo, ste, su, отрицание (nisam…), вопросы (Da li si…? / Jesi li…?), порядок слов. 56 вопросов.
- `glagoli-quiz.html` — 19 частых глаголов по лицам: пропуск окончания или местоимения, неправильные moći, hteti, ići, zvati se. 55 вопросов.
- `recnik.html` — личный словарь: добавляй слова вручную или нажатием на слово в разборе после ответа в тестах, потом тренируй их (сербский → русский, русский → сербский, ввод слова). Слова хранятся в браузере; перенести на другое устройство можно через текст внизу страницы.
- `index.html` — список тестов.

В каждом тесте: пояснение при ошибке, перевод и разбор предложения по частям речи, переключатель латиница / кириллица / вперемешку, шпаргалка и алфавит, повтор ошибок в конце. Незаконченный тест можно продолжить с того же места.
