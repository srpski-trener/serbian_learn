# serbian_learn

Интерактивные тренажёры сербского для русскоговорящих. Каждый тест — один HTML-файл, открывается в любом браузере без установки.

- `biti-quiz.html` — глагол biti в настоящем: sam, si, je, smo, ste, su, отрицание (nisam…), вопросы (Da li si…? / Jesi li…?), порядок слов. 87 вопросов, можно выбрать одну тему или пройти все подряд.
- `glagoli-quiz.html` — 19 частых глаголов по лицам: пропуск окончания или местоимения, неправильные moći, hteti, ići, zvati se. 55 вопросов.
- `se-quiz.html` — возвратные глаголы с se: нужен ли se, форма глагола, место se в предложении, безличное se (Izdaje se stan). 53 вопроса.
- `brojevi-quiz.html` — числа, даты и деньги: как читать числа, форма слова после числа (dva stana, pet stanova), даты (dvadeset prvog oktobra), слова про деньги и платежи. 84 вопроса.
- `pisanje-quiz.html` — правописание: č/ć, đ/dž, «пишется как слышится», большая буква, слитно или раздельно, запятые. 57 вопросов.
- `red-quiz.html` — порядок слов: предложение собирается из слов, главное правило о коротких словах на втором месте. 37 заданий.
- `mix-quiz.html` — все темы вперемешку: каждый раз 50 случайных вопросов из всех тестов.
- `recnik.html` — личный словарь: слова добавляются только из тестов (нажатием на слово в разборе после ответа), потом их можно тренировать (сербский → русский, русский → сербский, ввод слова). Слова хранятся в браузере; перенести на другое устройство можно через текст внизу страницы.
- `pravila.html` — все шпаргалки на одной странице плюс разборы частых вопросов.
- `index.html` — список тестов.

В каждом тесте: пояснение при ошибке, перевод и разбор предложения по частям речи, переключатель латиница / кириллица / вперемешку, шпаргалка и алфавит, повтор ошибок в конце. Незаконченный тест можно продолжить с того же места.
