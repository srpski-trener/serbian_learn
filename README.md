# serbian_learn

Интерактивные тренажёры сербского для русскоговорящих. Каждый тест — один HTML-файл, открывается в любом браузере без установки.

- `biti-quiz.html` — глагол biti в настоящем: sam, si, je, smo, ste, su, отрицание (nisam…), вопросы (Da li si…? / Jesi li…?), порядок слов. 56 вопросов.
- `glagoli-quiz.html` — 19 частых глаголов по лицам: пропуск окончания или местоимения, неправильные moći, hteti, ići, zvati se. 55 вопросов.
- `index.html` — список тестов.

В каждом тесте: пояснение при ошибке, перевод и разбор предложения по частям речи, переключатель латиница / кириллица / вперемешку, шпаргалка и алфавит, повтор ошибок в конце.

Чтобы открыть с телефона по ссылке, можно включить GitHub Pages: Settings → Pages → Deploy from branch → `main`.
