Род и окончания

Какого рода слово, moj / moja / moje, множественное число (studenti, gradovi, ulice, slova) и профессии для женщин. Если ошибёшься, будет объяснение.

Мн. число-i: studenti; короткие -ovi / -evi: gradovi, brojevi-a → -e: ulice; согласный → -i: stvari-a: slova; ime → imena
  • Род смотрим по окончанию, а не по русскому переводу: olovka (карандаш) и stolica (стул) женского рода, prezime (фамилия) среднего, posao (работа) мужского.
  • Мужской род во мн. числе: -i (student → studenti, stranac → stranci). Перед -i: k → c (učenik → učenici), g → z (dijalog → dijalozi), h → s (orah → orasi).
  • Короткие слова мужского рода (один слог) получают -ovi: grad → gradovi, sto → stolovi. После j, lj, nj, č, ć, đ, ž, dž, š получается -evi: broj → brojevi, ključ → ključevi. Исключения: dan → dani, đak → đaci.
  • Мужской род на -a: komšija → komšije, но turista → turisti.
  • Профессии, она: -ka (lekar → lekarka, profesor → profesorka, programer → programerka, policajac → policajka), -ica (učitelj → učiteljica, pevač → pevačica, učenik → učenica, konobar → konobarica, kuvar → kuvarica), особые: student → studentkinja, ekonomista → ekonomistkinja, komšija → komšinica, kolega → koleginica.
